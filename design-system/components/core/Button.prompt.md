Botão de ação do Mapiii; uma ação primária por tela.

```jsx
<Button icon="enviar" size="xl" fullWidth>Enviar foto</Button>
<Button variant="secondary">Corrigir</Button>
<Button variant="text" size="md">Alterar local</Button>
<Button variant="danger">Excluir foto</Button>
```

- Foco por teclado: anel duplo (3 px fundo + 3 px Space Indigo) automático.
- Desabilitado usa borda tracejada, não só cor mais clara.
- `pill` para o botão flutuante "Registrar" do mapa.
