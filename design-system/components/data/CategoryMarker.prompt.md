Marcador de categoria (forma + ícone + cor) — mapa, tags, ranking.

```jsx
<CategoryMarker category="calcada_quebrada" size={40} title="Calçada quebrada" />
```

Formas: sem_rampa_ou_degrau = quadrado roxo · obstaculo_no_caminho = triângulo laranja · calcada_quebrada = losango rosa · calcada_estreita = hexágono verde-água · sem_problema = círculo azul. Exporta `CATEGORIES` com rótulos.
