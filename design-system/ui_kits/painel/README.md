# UI kit · Painel da prefeitura (desktop)

`Dashboard.jsx` — barra lateral, KPIs, mapa de calor com posições do ranking, tabela de trechos por prioridade e **Exportar CSV** (gera o arquivo de verdade). Passar o mouse numa linha destaca o ponto no mapa. Dados de exemplo (São Paulo, Subprefeitura Sé) são fictícios.
