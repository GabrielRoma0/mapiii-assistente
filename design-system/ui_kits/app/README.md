# UI kit · App cidadão (PWA)

Recriação clicável das telas mobile definidas na identidade (`Mapiii Identidade Visual v2.dc.html`, seção 06).

- `LoginScreen.jsx` — nome + perfis de mobilidade (múltipla escolha)
- `MapScreen.jsx` — mapa colaborativo, filtros por categoria, folha inferior, botão Registrar
- `CaptureScreen.jsx` — foto, local, descrição opcional, Enviar foto
- `DetailScreen.jsx` — classificação da IA com % por categoria, selo de dúvida, gravidade, Confirmar/Corrigir
- `Phone.jsx` — moldura 390 × 844 e placeholder de foto

Fluxo: Entrar → Mapa → Registrar → Enviar → Detalhe → Confirmar.
