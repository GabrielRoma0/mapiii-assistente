Ficha `passe-livre-interestadual`. Texto da página do gov.br baixado pelo Claude Code em 09/11/2026 (`2026-11-09-govbr-passe-livre.md`). O endereço foi achado numa busca na web; a ficha usa só o texto da página oficial.
