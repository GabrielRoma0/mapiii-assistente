1. Página "Cadastre-se no Atende+" (menu do topo de sptrans.com.br/atende): documentos, laudo ou formulário médico, onde entregar.
2. "Conheça os requisitos aqui" e "Consulte o regulamento do serviço Atende+ aqui", na página de login (abrem sem credencial).
3. Print da Lei 16.337/2015 no catálogo (o link acima), para a `base_legal`.
