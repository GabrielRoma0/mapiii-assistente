# Sons para baixar (lista pronta)

Todos com licença **CC0** (livre, sem exigir crédito), encontrados no Openverse em 10/11/2026. O Freesound recusa download automático, então a dupla baixa à mão.

**Como baixar cada um:** abra o link, clique em **Download** (o Freesound pede login gratuito; dá para entrar com Google) e salve nesta pasta (`video/sons/`) com o **nome da coluna "Salvar como"**, mantendo a extensão do arquivo (.wav, .mp3...). Se não gostar do som, use a 2ª opção.

Depois, envie os arquivos para o GitHub (Add file → Upload files na pasta `video/sons/` da branch) ou passe para o Claude Code. O `CREDITOS.txt` é preenchido pelo Claude Code com o que foi usado.
